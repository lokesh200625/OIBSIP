# OIBSIP – Web Development Projects

A collection of web development tasks completed as part of the Oasis Infobyte Internship (OIBSIP). Each project is built with HTML, CSS, and JavaScript and lives in its own folder.

## Projects

### Task 1: Landing Page
A static, responsive landing page.
- **Technologies:** HTML5, CSS3
- **Folder:** [1.Landing Page](./1.Landing%20Page)

### Task 2: Personal Portfolio
A personal portfolio website that introduces the developer, their skills, and their work.
- **Technologies:** HTML5, CSS3, JavaScript
- **Folder:** [2.Portfolio](./2.Portfolio)

### Task 3: Temperature Converter
A web app that converts temperatures between Celsius, Fahrenheit, and Kelvin, with input validation for invalid entries.
- **Technologies:** HTML5, CSS3, Vanilla JavaScript
- **Folder:** [3.Temperature](./3.Temperature)

## How to Run

1. Download or clone this repository.
2. Open the project folder you want to view.
3. Open `index.html` in any web browser.

No installation or build tools are required.
